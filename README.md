# CheckRow

A Google Workspace–style to-do list app.

## Brand

| File | Use |
| --- | --- |
| `brand/checkrow-icon.svg` | Main app icon (light) |
| `brand/checkrow-icon-dark.svg` | App icon for dark backgrounds |
| `brand/checkrow-favicon.svg` | Simplified mark for 16 px favicons |
| `brand/png/` | PNG exports at 16, 32, 48 and 128 px (Chrome / Edge store sizes) |
| `brand/design/` | Source of the logo canvas (CheckRow logo artboard) |

**Palette**

- Row blue `#2F6FEB`
- Done green `#22A06B`
- Row amber `#F2A900`
- Ink `#1F2328`

**Wordmark:** "CheckRow" set in [Outfit](https://fonts.google.com/specimen/Outfit) Medium, −1.5 px tracking.

Branding only so far. App code to come.
